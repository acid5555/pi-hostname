## 📂 Features

- **Automatic Hostname Tracking:** The extension automatically records the hostname when a new session is created.
- **Seamless Resuming:** When you resume a session on a different machine, it informs the LLM of the hostname change.
- **User-friendly Interface:** Designed for simplicity, this tool requires no technical skills to operate.

## 📍 Usage

Using pi-hostname is straightforward:

1. **Create a New Session:** When you start a new session, your hostname is logged automatically.
2. **Resume on the Same Machine:** If you resume the session on the same computer, everything will function as usual.
3. **Resume on a Different Machine:** If you open the session on another machine, the LLM will receive a context message indicating the session's original hostname. This helps in avoiding confusion from mismatched paths or missing tools.
